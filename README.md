
# Kite P&L Automation using Python

## Project Overview
This project automates the calculation of intraday trading
Profit & Loss (P&L) and transaction charges using Python.

## Problem Statement
Analyze trading order data and calculate brokerage,
STT/CTT, exchange transaction charges, SEBI charges,
GST and stamp duty using NSE equity intraday rates.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Key Features
- Data cleaning and preprocessing
- Filtering MIS intraday trades
- Handling cancelled and rejected orders
- Trade-wise transaction charge calculation
- Stock-wise weighted average price analysis
- Gross P&L and Net P&L calculation

## Project Files
- orders.csv – Input trading dataset
- Kite_PnL_Analysis.ipynb – Python solution
- Problem_Statement.pdf – Project requirements

## Output
An Excel workbook containing:
1. Individual Trade Charges
2. Stock-wise and Type-wise Analysis
3. Overall Stock-wise P&L Summary
